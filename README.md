
# VHDL Edge Detection System

**Digital System Design | VHDL | Image Processing | 7-Segment Displays**

## Project Overview

A university digital system design project focused on implementing an edge detection system using VHDL.

The system processes a 10x10 grayscale image matrix, performs gradient-based edge detection, and identifies the starting and ending coordinates of detected edges.

The resulting coordinates are presented using four 7-segment display outputs.

## Project Objectives

- Implement an image-processing algorithm using VHDL.
- Process a 10x10 grayscale image matrix.
- Detect edges using gradient calculations.
- Apply an edge detection threshold of 70.
- Determine the starting and ending coordinates of detected edges.
- Represent the coordinates using four 7-segment displays.

## System Architecture

The system consists of the following functional stages:

1. Image data input
2. Gradient calculation
3. Threshold comparison
4. Edge coordinate detection
5. 7-segment display output
